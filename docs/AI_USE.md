# Libraries and AI use

The user supplied idea-selection material and the frontend brief. Claude contributed the Writ proposal/frontend direction. OpenAI Codex implemented and revised this frontend, mock adapter, proposed testnet bindings, tests, docs and SVG generator.

Direct tools/libraries: React, React DOM, React Router DOM, Vite, its React plugin, TypeScript, Fontsource Public Sans/Courier Prime, NEAR Connect, near-api-js, Vitest, Playwright, axe-core's Playwright integration, Prettier, and the starter's optional Oxlint. Exact dependencies are locked in package-lock.json. No UI kit, Tailwind or CSS-in-JS runtime.

The Sites skill's local preview/validation workflow was consulted. The project uses the requested Vite repository and Vercel/Netlify static configuration; Sites hosting was not used.

Public NEAR documentation informed integration. No competitor implementation was copied. Fonts retain their SIL Open Font Licenses. Tests/screenshots establish frontend behavior, not a contract audit, deployment, financial security or competitive superiority.
